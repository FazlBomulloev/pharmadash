# ТЗ: редизайн PharmDash (7 экранов)

Репозиторий: `FazlBomulloev/pharmadash`, ветка `main`, фронтенд в `frontend/` (React 19 + Vite + TypeScript, Tailwind v4, recharts, @tanstack/react-table, @tanstack/react-virtual, lucide-react, react-router 7).

## 1. Обзор

Переделываем визуальную часть всех экранов аналитики фармрынка: Рынки, Обзор, Дашборд МНН, Скоринг, Цены аптек (БДЦ), Настройки рынка, Загрузка данных. Цель: спокойный светлый интерфейс с одним тёмным «hero»-блоком наверху каждого ключевого экрана, насыщенной палитрой для данных (категории скоринга, классы ATC, страны, аптеки), крупной типографикой цифр и мягкими анимациями появления. Боковые панели вместо раскрывающихся строк. Бизнес-логика и API остаются, но для нескольких новых блоков нужны новые поля — см. раздел 9.

## 2. О файлах дизайна

Папка `designs/` — **HTML-прототипы, а не код для копирования**. Они показывают точный внешний вид и поведение. Задача — **воссоздать их в существующем фронтенде** (`frontend/src`) на React + Tailwind, используя текущие страницы, роутинг, `api/client.ts`, `types/api.ts`, хуки. Данные в прототипах — заглушки (захардкожены в `<script data-dc-script>` каждого файла), их нужно заменить реальными данными из API.

Как открыть прототип: положить папку `designs/` целиком и открыть любой `*.dc.html` в браузере (рядом обязателен `support.js`). Разметка — в `<x-dc>…</x-dc>`, инлайн-стили; логика и мок-данные — класс `Component` в `<script type="text/x-dc" data-dc-script>` (функция `renderVals()` показывает, какие значения куда подставляются).

## 3. Точность

**High-fidelity.** Цвета, размеры шрифтов, отступы, радиусы, состояния hover и анимации — финальные. Воспроизводить пиксель-в-пиксель. Где Tailwind-шкала не совпадает — использовать arbitrary values (`text-[17px]`, `rounded-[20px]`) или токены из `theme.css`.

## 4. С чего начать (порядок работ)

1. Подключить `theme.css` (токены Tailwind v4 `@theme` + шрифт Onest) в `frontend/src/index.css` после `@import "tailwindcss";`. Заменить шрифт Inter → Onest, фон `#f8fafc` → `#f4f4f1`.
2. Тёмная тема: в репо есть `useTheme`/`dark:`. Новый дизайн сделан **только для светлой темы**. Решение по умолчанию: тёмную тему пока отключить (принудительно `light`) или оставить существующие `dark:`-классы без изменений — согласовать с владельцем; в новых компонентах `dark:` не добавлять.
3. Создать общие UI-компоненты (раздел 6) в `frontend/src/components/ui/`.
4. Переверстать `Layout`/`Sidebar` (раздел 5).
5. Переверстать экраны в порядке: Обзор → Дашборд МНН → Скоринг → БДЦ → Рынки → Настройки → Загрузка.
6. Добавить анимации (раздел 8).

## 5. Каркас приложения

**Layout** (`components/layout/Layout.tsx`, `Sidebar.tsx`, `Header.tsx`): двухколоночный — сайдбар 224px слева, контент справа. Отдельный верхний `Header` в новом дизайне не нужен: заголовок и фильтры живут в шапке каждой страницы.

**Сайдбар**: `width:224px; position:sticky; top:0; height:100vh; padding:20px 12px; background:#fbfbfa; border-right:1px solid #ebebe7`, вертикальный flex, `gap:24px`.
- Логотип: квадрат 24×24, `border-radius:7px`, фон `oklch(0.47 0.14 262)`, белая «P» 13px/700; рядом «PharmDash» 15px/700, `letter-spacing:-0.01em`.
- Переключатель рынка (карточка): `padding:9px 10px; border-radius:9px; background:#fff; border:1px solid #ebebe7`. Строка 1 — название рынка 13px/600; строка 2 — «2023–2025 · 17 рег.» 11px `#8b8f97`; справа «⌄».
- Навигация внутри рынка: Обзор, Дашборд МНН, Скоринг, Цены аптек (БДЦ), Настройки. Пункт: `padding:8px 10px; border-radius:8px; font-size:14px`. Активный: `background:#ebebe7; color:#16181d; font-weight:600`. Неактивный: `color:#5d616a`, hover `background:#f0f0ed; color:#16181d`.
- Внизу (`margin-top:auto`): «Все рынки», «Загрузка данных» — тот же стиль.
- На странице «Рынки» сайдбар без переключателя рынка и без навигации по рынку: только «Все рынки» (активный) и «Загрузка данных».

**Контент**: `main` — `flex:1; min-width:0; padding:28px clamp(20px,3vw,40px) 72px; display:flex; flex-direction:column; gap:24px; max-width:1360px` (Скоринг/БДЦ — 1440px; Настройки/Загрузка — 940px; Рынки — 1120px).

## 8. Анимации и переходы

- **Count-up и прорисовка графиков** (Обзор, Дашборд): одно значение прогресса `t` 0→1 за **1900 мс**, easing easeInOutCubic (`t<.5 ? 4t³ : 1−(−2t+2)³/2`). От `t` зависят: значения BigNumber/KPI, `stroke-dashoffset` линии графика (`pathLength=1`, `dasharray=1`, `offset=1−e`), opacity заливки, ширины полосок (DivergingBar, производители, критерии), высоты столбиков. **Обязательно**: если вкладка не видна (`document.visibilityState!=='visible'`) или для печати — сразу показывать конечное состояние; плюс таймаут-страховка ~2,6 с, который выставляет `t=1`. Учитывать `prefers-reduced-motion` (уже есть в index.css) — без анимации.
- **Появление страницы**: шапка — opacity 0→1 + `translate 0 −8px→0` за 700 мс; карточки и hero (верхнего уровня) — opacity 0→1 + `translate 0 16px→0` за 900 мс, задержка 120 мс + 90 мс × индекс; easing `cubic-bezier(.22,.61,.36,1)`; fill backwards.
- **Смена вкладки / появление новых карточек**: 650 мс, шаг 70 мс.
- **SidePanel**: панель `translateX(48px)→0` + opacity за 480 мс; оверлей fade 320 мс.
- **Dropdown/Autocomplete**: `translateY(−6px) scale(.98)→none` + opacity, 220 мс.
- **Плашка «Изменено параметров»**: снизу `translateY(18px)→0`, 420 мс.
- **Hover**: у всех интерактивных строк/кнопок `transition: background-color .2s, color .2s, filter .2s, box-shadow .2s`. Строки списков: hover `#f6f6f3`/`#f7f7f4`, кликабельные строки со SidePanel — `#f4f5fa`. Кнопки на тёмном — `oklch(1 0 0 / .06–.18)`.
- Для анимаций в React: `framer-motion`/`motion` (если допустимо добавить зависимость) или CSS `@keyframes` + `animation-delay` через style. Страховка от «застрявших» невидимых элементов обязательна в любом варианте.

7. **Сравнение цен** (БДЦ): все позиции той же ТМ + дозировки в других аптеках.
8. **Пересчёт для Настроек**: число МНН в каждой зоне при текущих порогах и сколько МНН отсекает каждый стоп-фильтр (preview без сохранения).
9. **Скоринг**: серверная пагинация с total.
10. **Рынки**: объём последнего года и рост для карточек.

## 10. Состояние (по экранам)

- Обзор: `sector`, `year`, `atc`, `mode (usd|un)`, `country` (открытая панель), `ctab`, `form`, `producer` (открытая панель). Фильтры желательно хранить в URL query.
- Дашборд: выбранный МНН (в URL), `tab`, `lf`, `dose`, `year`, `country` (панель), `regAll`, состояние автокомплита (`focus`, `highlight`).
- Скоринг: `cat`, `q`, `mode`, `sort {key, asc}`, `lf`, `dose`, `page`, `pageSize`, `selected` (панель).
- БДЦ: `q`, `pharmacies[]`, `mnn`, `producer`, `country`, `form`, `priceMin/Max`, `sort`, `selected`, `running{slug}`.
- Настройки: черновик весов/порогов/стоп-фильтров/стран + базовая версия для сравнения (`changed`).
- Загрузка: `step`, `kind`, поля рынка, файл, лист, строка заголовков, маппинг.

## 11. Критерии приёмки

- Все 7 экранов визуально совпадают с прототипами на ширине 1440px и корректно перестраиваются до 768px (карточки переносятся, таблицы скроллятся по горизонтали, текст не обрезается и не переносится в числах).
- Нет полосы прокрутки у ряда вкладок Дашборда.
- Клик по стране и по производителю на Обзоре открывает соответствующую панель; одновременно открыта одна панель; Esc и клик по фону закрывают.
- Фильтр ATC с Обзора применяется ко всем блокам страницы.
- Autocomplete МНН и стран работают с клавиатуры.
- Пагинация Скоринга серверная, сбрасывается при смене фильтров.
- Анимации не оставляют элементы невидимыми в фоновой вкладке / при печати; при `prefers-reduced-motion` — без анимаций.
- Контраст текста ≥ 4.5:1 (на hero использовать указанные светлые оттенки).
